# Student Daily Login Screenshot Portal

A web-based portal designed to simplify daily student login screenshot collection and monitoring.

## Features

- Student, CR, and Admin role-based login
- Daily login screenshot upload
- Date-wise screenshot organization
- CR dashboard to monitor submitted and not-submitted students
- Admin dashboard for management
- Screenshot viewing and report downloads

## Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Database:** MySQL / TiDB Cloud
- **Deployment:** Render
- **Version Control:** Git and GitHub

## User Roles

- **Student:** Upload daily login screenshots.
- **CR:** Monitor student submissions and access reports.
- **Admin:** Manage and monitor portal activities.
